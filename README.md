# EV Battery Performance Simulator

## Overview

The EV Battery Performance Simulator is a Python-based engineering project developed to simulate and analyze important parameters of an Electric Vehicle (EV) battery system.

The simulator provides an interactive environment for understanding battery behavior under different operating conditions. It focuses on parameters such as State of Charge (SOC), battery voltage, current, power, energy consumption, and charging/discharging behavior.

## Key Features

- 🔋 Battery State of Charge (SOC) analysis
- ⚡ Voltage and current calculations
- 🔌 Charging and discharging analysis
- 📊 Power and energy calculations
- 📈 Battery performance visualization
- 🚗 EV-oriented battery simulation
- 🐍 Python-based implementation

## Technologies Used

- Python
- Streamlit
- Data Processing
- Data Visualization
- Electrical Engineering Concepts
- Electric Vehicle Technology

## Project Objective

The objective of this project is to develop a simple and interactive simulation platform for understanding EV battery performance and applying electrical engineering concepts through Python programming.
